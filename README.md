# Движок тождеств

Проверяет равенства выражений над множествами и показывает контрпример, если равенство неверно.

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
./build/bonus --demo
```

Пример:

```sh
./build/bonus 'A&(B|C)' '(A&B)|(A&C)' 6
```

Переменные: `A`–`Z`. Операции: `~` (дополнение), `&` (пересечение), `\` (разность), `^` (симметрическая разность), `|` (объединение). Скобки поддерживаются. Универсум содержит от 0 до 64 элементов.

`--slow` запускает полный перебор, `--bench` сравнивает оба способа для четырёх переменных и `n` от 1 до 8. Последний замер занимает около минуты.
